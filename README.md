# Cynthia Wilkinson Portfolio Website

A simple static website for Cynthia Wilkinson's cybersecurity and technology delivery portfolio.

Upload these files to the root of the GitHub repository:

- index.html
- styles.css
- README.md

Suggested GitHub Pages setup:

1. Go to repository Settings.
2. Go to Pages.
3. Set source to Deploy from a branch.
4. Select main branch and root folder.
5. Save.
6. Later, add the custom domain: cynthiawilkinson.com.au.
